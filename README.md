# Sistech 3D 분석 도구

3D-VIEW by Sistech (https://3dview.sistech3d.com/ko/viewer) 위에 얹어 쓰는 3D 분석 메뉴입니다.
왼쪽에 아이콘 메뉴(선택 / 측정 / 그리기 / 위장)와 320px 패널이 생기고, 위쪽 프로젝트 목록에서 프로젝트를 바꿀 수 있습니다. (사진 중첩과 점검은 시제품 파일을 추가로 실행하면 "사진", "점검" 메뉴가 더해집니다.)

## 기능

### 선택
- 클릭: 그려 둔 도형이나 측정 결과를 클릭해서 선택 (Shift/Ctrl 클릭으로 여러 개). 모델 바닥을 클릭하면 위도/경도/높이 확인, 좌표 복사, 그 자리에 점 그리기
- 영역 선택: 폴리곤 또는 사각형으로 영역을 그려서 그 안에 걸치는 것 / 완전히 들어온 것만 선택
- 선택한 항목의 길이/면적/성토/절토 합계, 보기, 숨기기, 삭제(두 번 눌러 확인)
- 다른 기능이 선택 대상을 추가할 수 있는 `SisMenu.registerSource` 제공

### 측정
- **거리**: 3D 거리와 수평 거리
- **높이**: 높이차, 수평 거리, 경사 거리
- **면적**: 수평 면적(2D 환산)과 표면 면적(클릭한 점을 이은 3D 면). 모델에는 색을 입히지 않고 3D 면만 반투명으로 표시
- **체적**: 경계점을 이은 면(또는 수평면)을 기준으로 성토(주황) / 절토(하늘색) 계산. 3D 복셀 방식이라 공중에 떠 있는 구조물(간판 등)도 처리. 타일 로딩 대기는 최대 20초

### 그리기
- 점, 폴리라인, 폴리곤, 사각형, 원, 화살표, 문자
- 색 팔레트, 선 굵기, 채우기 투명도, 지형 덮기(선택)
- 꼭짓점 편집, 도형 통째로 이동, 개별 표시/숨김 체크박스, 전체 표시 체크박스
- 길이/면적은 지도 위가 아니라 왼쪽 패널에만 표시
- GeoJSON 내보내기/불러오기, 프로젝트별 자동 저장(브라우저 localStorage)
- 되돌리기: Backspace 또는 Ctrl+Z, 완료: Enter 또는 오른쪽 클릭, 취소: Esc

### 위장 (보안구역 숲 위장)
- 선택 메뉴에서 그린 폴리곤 안쪽만 주변 숲처럼 보이게 만듭니다. 폴리곤 바깥은 그대로입니다.
- 원본 3D 타일은 수정하지 않습니다. 폴리곤 안 원본은 화면에서만 가리고, 생성한 GLB 패치를 그 자리에 올립니다.
- 주변 높이와 색을 읽어 경계가 자연스럽게 이어지도록 만들고, 경계 퍼짐 폭, 숲 느낌, 밝기, 채도, 나무 크기, 수관 높이 변화, 높이 보정을 조절할 수 있습니다.
- 만든 패치는 GLB로 저장할 수 있습니다(폴리곤 정보 포함).

### 사진 중첩 (시제품)
드론 사진의 위치·방향(EXIF/XMP)을 이용해 사진을 3D 모델 위에 겹쳐 보는 기능입니다. 파일: `photo-overlay-prototype.js` (메뉴 파일을 실행한 뒤 추가로 실행)
- 사진 중첩 켜기/끄기, 투명도, 카메라에서 사진 면까지 거리
- **모델 면 투영**: 원본 타일은 건드리지 않고, 화면에 그릴 때 모델 표면에 사진 색을 입힘(촬영 위치 반대쪽 면은 제외)
- 촬영 위치로 이동 (사진과 같은 방향·화각), 렌즈 왜곡 보정 적용
- **위치·방향 미세 조정**: 동서/남북/고도 이동, 방위/상하/기울기, 화각 배율. 값은 사진별로 브라우저에 자동 저장
- **자동 맞춤(이미지 매칭)**: 사진 속성 값에서 시작해, 사진과 모델 화면의 같은 지점을 찾아 위치와 방향을 자동 보정(OpenCV.js를 인터넷에서 불러옴). 되돌리기 지원
- 현재는 사진 한 장(DJI M3E)의 속성값이 코드에 들어 있고, 사진 파일 데이터는 `window.__pjb64`(JPEG base64)로 넘겨 줘야 하는 시제품입니다. 사진 직접 선택/폴더 선택은 아직 없습니다.
- 사진의 절대고도는 WGS84 타원체고로 보고 사용합니다. 인천-1 시험에서는 모델이 약 20 m 낮게 맞는 결과가 나왔으므로 고도 보정이 필요할 수 있습니다.

### 점검 보고 (시제품)
사진 중첩 화면에서 균열 같은 문제 지점을 표시하고 내용을 입력하면 보고서를 만들어 주는 기능입니다. 파일: `inspection-feature.js` (메뉴 파일과 `photo-overlay-prototype.js` 를 실행한 뒤 마지막에 실행)
- 표시 방식: 지점(핀), 선(3D 길이), 영역(3D 면적, 벽면도 가능)
- 항목마다 종류(균열, 박리·탈락, 누수·백태, 침하·변형, 파손·손상, 오염·식생, 기타), 정도(경미/보통/심각, 색 구분)를 고르고, **제목(필수), 점검 내용, 조치 의견은 직접 입력**합니다. 자동으로 채워 넣는 내용은 없습니다.
- 저장할 때 증빙 이미지를 자동 캡처: 현재 화면, 사진 중첩 확대, 3D 모델만 확대, 원본 사진 크롭(원해상도)
- 목록에서 위치 이동, 내용 수정, 삭제(두 번 눌러 확인), 지도 표시 켜기/끄기
- 보고서: A4 인쇄용 HTML(요약표, 전체 위치 개요, 목록, 항목별 상세), 인쇄/PDF 저장, CSV(엑셀용)
- 항목은 브라우저 IndexedDB에 프로젝트별로 자동 저장됩니다.
- 사진 중첩 시제품에 의존하므로 사진 직접 선택 등 같은 제약이 있고, 위치는 수 미터 오차가 있을 수 있습니다.

## 사용 방법
사이트가 다른 주소의 요청을 막기 때문에, 뷰어 탭 안에서 직접 실행해야 합니다.

1. https://3dview.sistech3d.com/ko/viewer 를 열고 모델이 뜰 때까지 10~15초 기다립니다.
2. 개발자 도구(F12) 콘솔에 `sistech-analysis-menu.js` 의 내용을 붙여 넣고 Enter.
3. 왼쪽에 "3D 분석 메뉴"가 나타납니다. (사진 중첩, 점검은 `photo-overlay-prototype.js`, `inspection-feature.js` 를 같은 방식으로 이어서 실행)

새로고침하면 사라지므로 다시 실행해야 합니다. 사용자 스크립트(Tampermonkey 등)로 등록하면 자동으로 실행할 수 있습니다.

## 참고
- 점은 건물 벽이 아니라 지면/지붕 면에 찍어 주세요.
- 체적 계산은 모델이 모두 로드된 뒤에 해야 정확합니다.
- 위장은 화면 표시용입니다. 원본 데이터에 합치려면 저장한 GLB와 폴리곤 정보로 서버에서 따로 처리해야 합니다.
